# NODAL — New horizon

La propuesta traduce la instrucción del usuario a una interfaz mediterránea, contemporánea y dinámica. El objetivo es un producto que se sienta cuidado y deseable sin recurrir a fotografías, neón ni saturación de controles.

## Dirección

- **Color:** azul profundo como ancla; gris mineral para estructura; salvia y aqua para luz, acciones y superficies.
- **Composición:** jerarquía editorial amplia, espacio respirable y un punto focal visual reconocible.
- **Tipografía:** Manrope y DM Sans alojadas con la aplicación. Titulares expresivos y texto funcional legible.
- **Materia:** luz, profundidad y transparencia contenida. Formas originales evocan costa, horizonte y movimiento sin simular una escena documental.
- **Movimiento:** transiciones suaves que orientan; respuesta de controles inmediata. Reduced motion limita la animación.
- **Producto:** navegación principal de cinco destinos, detalles contextuales y acciones visibles. Estados de ejemplo claramente identificados.

## Paleta base implementada

| Token o superficie | Color | Función |
| --- | --- | --- |
| `--ink` | `#203F48` | Texto principal |
| `--navy` | `#1E424F` | Ancla azul profunda |
| Fondo | `#F3F5F3` | Gris mineral luminoso |
| `--surface` | `#F7F9F6` | Superficie clara |
| `--mint` | `#D4E4CD` | Salvia suave |
| `--line` | `#D9E1DE` | Estructura y divisiones |
| Agua del arte original | `#91B6BA` | Aqua mediterráneo |

Las preferencias Costa, Océano y Salvia ajustan los acentos y algunas superficies. El contraste del texto funcional se comprueba por separado de los colores decorativos.

## Imágenes, en otra etapa

Esta versión no usa fotos de DJs, clubs, venues ni festivales. No hay bloques grises esperando imágenes ni datos fotográficos falsos.

La próxima etapa puede explorar imágenes creativas de IA con atmósferas de sunset en Ibiza o la Costa Azul, calidad alta y paletas aqua/verdes. Deberán identificarse como imágenes generadas o conceptuales; no se presentarán como evidencia de una actuación real, un artista verificado o un venue auténtico. La identidad, los derechos y el contexto de publicación se revisarán antes de incorporarlas.

## Lo que esta entrega permite evaluar

Aspecto visual, distribución, navegación, lectura de oportunidades de ejemplo, filtros, estados locales, formularios visuales y accesibilidad básica. No valida autenticación, ofertas, bookings, pagos, mensajes o notificaciones de producción.

Los archivos de Casa Vista y la versión anterior no están disponibles para una comparación visual directa. La propuesta se basa en la descripción actual del usuario.
